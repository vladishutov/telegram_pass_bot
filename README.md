# Telegram-бот электронных пропусков

Бот для выдачи и проверки электронных пропусков на территорию.

## Роли

| Роль | Возможности |
|------|-------------|
| **Организатор** | Создаёт организации, назначает админов и охранников, выдаёт/аннулирует/продлевает пропуска, смотрит журналы |
| **Администратор** | Выдаёт/аннулирует/продлевает пропуска, смотрит активные пропуска и журналы. Не может назначать других админов |
| **Охранник** | Выбирает организацию → авторизуется → проверяет пропуска (пропустить/не пропускать) |
| **Гость** | Видит свои активные пропуска, открывает пропуск отдельным сообщением |

## Установка локально

git clone <your-repo-url>
cd telegram-pass-bot
pip install -r requirements.txt
export BOT_TOKEN=ваш_токен_от_BotFather
python bot.py

## Деплой на Render

1. Залейте код на GitHub
2. На render.com создайте новый Web Service из репозитория
3. render.yaml подхватится автоматически
4. Добавьте переменную окружения BOT_TOKEN
5. Деплойте
